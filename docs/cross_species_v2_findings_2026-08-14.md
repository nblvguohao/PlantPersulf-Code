## 0. 与 v1 的差异

1. 加入番茄（kiae271，99 个坐标验证位点 / 88 蛋白）为第 4 个物种：两两检验从 3 对增加到 6 对，
   新增 n-way 保守谱与置换检验。
2. 新增**检测下限**（`conservation_detectability_floor`）：对每一对报告"要达到 p<0.05
   最少需要多少个共同持久化家族"，使不显著的结果可解释。
3. 新增**模型置信度对照**（`plddt_context_test` / `filter_rows_by_plddt` /
   `filter_sasa_rows_by_plddt`）。**这一项推翻了 v1 的结构层结论**，见 §3。
4. 番茄 76 个 AlphaFold 结构由 v4 强制重下为 v6（`--force`），使 registry 版本统一
   （2,081 条 v6 + 1 条本地模型）。重下后所有数值逐位不变——版本混杂被排除，
   且结果对该版本升级不敏感。
5. kiae271 是全套数据中唯一的**差异**数据集（SlLCD1-OE vs WT），因此额外按
   `lcd_gain` / `wt_only` / `both` 分层复测。

## 3. 结构层结论更正（重要）

### v1 的结论

`docs/phase_z_evidence_audit.md` §5.5.2 记录："三个物种的持久化 Cys 比同蛋白内其他 Cys
更包埋，方向一致，真 SASA 与代理指标完全一致"，并将其作为交叉验证过的正面发现。

### v2 的对照结果

新增两项对照后，该结论**不成立**：

**(a) 持久化 Cys 与其他 Cys 的 AlphaFold 置信度本身就不同**

| 物种 | 阳性 pLDDT | 未标记 pLDDT | 差 | p |
|---|---|---|---|---|
| 拟南芥 | 83.8 | 82.0 | +1.81 | 0.1009 |
| 水稻 | 92.3 | 88.8 | **+3.54** | **0.0010** |
| 番茄 | 69.8 | 77.3 | **−7.50** | **0.0050** |
| 稻瘟菌 | 93.4 | 89.9 | **+3.49** | **0.0010** |

**(b) 只比较 AlphaFold 有把握的残基（pLDDT ≥ 70）后，SASA 差异全部消失**

| 物种 | residue SASA 差（全部 / ≥70） | SG SASA 差（全部 / ≥70） |
|---|---|---|
| 拟南芥 | −1.19 (p=0.55) / **−0.30 (p=0.86)** | −0.17 (p=0.88) / +0.66 (p=0.44) |
| 水稻 | −5.22 (**p=0.001**) / **−0.57 (p=0.49)** | −2.14 (**p=0.002**) / +0.15 (p=0.76) |
| 番茄 | +11.31 (**p=0.013**) / **+2.17 (p=0.53)** | +5.97 (**p=0.019**) / −0.81 (p=0.72) |
| 稻瘟菌 | −4.34 (**p=0.001**) / **+0.12 (p=0.85)** | −1.77 (**p=0.002**) / +0.46 (p=0.16) |

在 4 物种 × 3 度量 = 12 项置信度受限检验中，唯一仍显著者是番茄的接触代理
（−2.53，p=0.035，n=52），这与多重比较下的偶然预期相当，且与同物种的严格 SASA
度量（+2.17，p=0.53）不一致。

### 更正后的结论（可对外表述）

> 在同一蛋白内部比较时，被检出的持久化半胱氨酸与其他半胱氨酸在 AlphaFold
> 模型置信度上存在系统差异；一旦把比较限制在结构模型可靠的残基上，四个物种
> 都不再显示可检出的溶剂可及性差异。此前报告的"持久化位点更包埋"方向性
> 是模型置信度分层的伴随效应，不能作为独立的结构层机制证据。

### 为什么会这样（机制）

- 极低 pLDDT 区被预测为伸展链，SASA 天然偏高；高 pLDDT 区堆积紧密，SASA 偏低。
  因此 pLDDT 与 SASA 本身强相关。
- 质谱对柔性、易被蛋白酶接近的区域检出率更高，所以"被检出的位点"与
  "低置信度区域"之间存在与生物学无关的采样耦合。
- 水稻/稻瘟菌的阳性落在**较高**置信度区 → 表观"更包埋"；
  番茄的阳性落在**较低**置信度区 → 表观"更暴露"。同一个混杂，两个方向。

### 对本项目的直接后果

1. **番茄的 40% 阳性位点落在低置信度区**（86 → 52，pLDDT≥70 后），
   高于其他物种（拟南芥 82%、水稻 95%、稻瘟菌 97% 保留）。
2. 冻结模型的结构分支使用 contact proxy + pLDDT 两个特征。上述结果说明该分支
   可能部分在编码**模型置信度**而非结构生物学。这不影响冻结纪律（模型不改），
   但必须写进稿件的限制条款，并登记为下一代模型的必查项。
3. v1 的"结构层趋同性"不得再作为正面证据引用；`docs/phase_z_evidence_audit.md`
   §5.5.2 已追加更正指针。
