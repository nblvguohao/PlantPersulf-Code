# Style guide

- Stance: conservative, execution-oriented, innovation-aware.
- Use `persulfidation` as the project term; mention `S-sulfhydration` only when describing literature terminology.
- Use `positive` and `unlabeled`; never call an unobserved cysteine `negative`.
- Use `development`, `audit`, `target-label-free`, `blind`, and `prospective` only for their explicitly defined stages.
- Say “candidate prioritization” before blind validation; do not say “discovery” or “prediction confirmed”.
- Report all seeds/repetitions and paired intervals; never highlight only the best fold or seed.
- Separate model evidence, site-modification evidence, biochemical function, and causal phenotype.
- Do not state a journal tier as an expected result; state the evidence required for the intended claim level.
