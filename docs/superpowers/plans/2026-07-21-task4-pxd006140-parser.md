**Goal:** Parse the two registered PXD006140 OMSSA result files into deterministic, provenance-preserving PSM records and emit cysteine sites only when their coordinates match narrowly registered official UniProt sequences.

**Architecture:** Immutable records in `proteomics/metadata.py` define parser boundaries. `peptide_parser.py` performs fail-closed streaming OMSSA parsing and deterministic output publication, while `site_normalizer.py` loads registered FASTA bytes, verifies complete peptide slices, emits verified sites, and audits published output. The CLI only resolves arguments and prints deterministic JSON summaries.

**Tech Stack:** Python 3.10 standard library, existing PlantPersulf provenance/download modules, PyYAML configuration already in the project, pytest 9, Ruff, and strict mypy.

def _fixture_source(tmp_path: Path) -> ProteomicsSource:
    manifest_path = Path("tests/fixtures/real/PXD006140/source_manifest.json")
    manifest = json.loads(manifest_path.read_text(encoding="utf-8"))
    fixture_path = manifest_path.parent / manifest["fixture_file"]
    registry_path = tmp_path / "fixture_registry.tsv"
    with registry_path.open("w", encoding="utf-8", newline="") as handle:
        writer = csv.DictWriter(
            handle,
            fieldnames=("path", "sha256"),
            delimiter="\t",
            lineterminator="\n",
        )
        writer.writeheader()
        writer.writerow(
            {
                "path": fixture_path.resolve().as_posix(),
                "sha256": manifest["fixture_sha256"],
            }
        )
    return ProteomicsSource(
        study_accession="PXD006140",
        source_file=fixture_path,
        registry_file=registry_path,
        source_sha256=manifest["fixture_sha256"],
    )
