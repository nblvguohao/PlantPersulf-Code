# PlantPersulf 番茄盲法主线与跨作物零标签迁移副臂架构设计

> 日期：2026-08-11
>
> 状态：用户已逐节确认；正式规格待用户复核
>
> 范围：模型与验证架构，不授权实现、数据下载、训练或候选发布
> 依从：`docs/PlantPersulf_Code_TDD_Codex.md`、Gate 2 决策及项目科学完整性规则

## 1. 决策摘要

模型开发的唯一一级目标是：提高冻结模型在未来番茄盲法候选实验中的
Top-K 命中富集。采用“去偏的分层 PU 排序器”为主架构，轻量级 PU
排序集成为强制基线，暂停高容量多模态门控网络。

跨作物泛化不删除，但不设为与番茄并列的共同主任务。它作为同一次番茄
盲法实验中的**条件性零标签迁移副臂**：使用拟合和调参时不接触番茄
阳性标签的共享
模型生成少量番茄候选；只有计算稳定性闸门和实验功效闸门同时通过时，
才占用至多 25% 的非对照候选容量。当前阶段不启动第二作物湿实验。

这一安排保留高收益上行空间，同时把跨作物失败与番茄主结论隔离。

## 2. 成本—结果—收益比较

| 方案 | 新增计算工作 | 新增湿实验工作 | 当前预期结果 | 成功收益 | 失败代价 | 决策 |
|---|---:|---:|---|---|---|---|
| 仅做番茄盲法 | 中 | 中 | 中等偏高可解释性 | 高，但适用范围局限 | 低 | 保留为一级主线 |
| 立即设跨作物为共同主任务 | 高 | 很高，需要第二作物体系 | 低；当前 LOSO 接近基准 | 很高 | 高，会稀释主线与样本量 | 不采用 |
| 番茄主线 + 受限零标签迁移副臂 | 中等增量 | 低至中；复用番茄盲法 | 低至中，但可独立判定 | 很高，可增加前瞻跨作物证据 | 有界，不影响主终点 | 采用 |

判断依据不是跨作物生物学“不存在”，而是当前直接迁移证据弱：水稻
PXD072089 轨道约为 1.30 倍基准率，但 recall@50=0，且 3/5 seed 低于基线；
多物种联合模型留出番茄时约等于基准率。与此同时，PXD072089 提供了
929 个坐标核验位点，来自独立实验室、独立化学和独立作物，具有高数据
价值。因此它适合作为源域/方法开发证据，不足以成为新架构的未见 lockbox。
未来番茄盲法队列仍是唯一干净的主验证锚点。

## 3. 目标与非目标

### 3.1 一级目标

1. 对番茄蛋白组全部可追溯 Cys 位点生成可审计的生物学优先级。
2. 在预注册实验容量 K 下提高盲法命中富集，而非优化随机切分分数。
3. 输出排名不确定性、适用域和证据卡；不输出未经校准的绝对发生概率。
4. 冻结候选后完成全结果返回、匹配对照分析和 1–2 个位点机制闭环。

### 3.2 条件性二级目标

以水稻和拟南芥公开、注册数据作为源域，模型拟合、超参数和特征保留决策
不使用任何番茄阳性标签，对未来番茄盲法候选做零标签优先级测试。若副臂
显著富集，可主张“预注册的跨物种/跨作物零标签迁移至番茄”；在没有
第二个作物的
独立盲法复现前，不主张“通用跨作物预测器”。

KIAE271 番茄结果已经参与了总体研究问题和特征白名单的形成，研究者无法
回到完全未见番茄知识的状态。因此本副臂只声称**模型拟合与调参不使用
番茄标签**，不声称整个研究设计是 target-naive 或从未接触番茄证据。

### 3.3 非目标

- 不把未观测 Cys 当作实验阴性。
- 不用新生产、未公开且无完整来源链的数据替代公开数据。
- 不以 PPI、AF3、对接或 MD 结果参与首轮全蛋白组排名。
- 不以随机蛋白划分、同一研究内部切分或已查看的水稻数据证明外部泛化。
- 不在盲法结果返回后重排、加样本、调参或改变命中定义。

## 4. 模型边界与数据流

对每个位点区分两个概念：

- `S_bio`：目标条件下发生 persulfidation 的相对生物学倾向，是候选排序
  唯一可用分数。
- `q_obs`：真实阳性被发现型质谱观察并标注的倾向，只能用于训练期去偏、
  分层和敏感性分析，不能进入候选分数。

主数据流：

1. 注册的番茄参考蛋白组生成全部 Cys 候选和坐标。
2. 核验 accession、序列、Cys 坐标、来源文件和 SHA256。
3. 生成对全候选一致可用的核心生物学特征。
4. 训练番茄主排序器 `S_T`，并与强制轻量基线 B 比较。
5. 仅对结构质量达标的候选计算受限结构残差；结构缺失时回退到序列分数。
6. 生成集成排名、排名区间和适用域标记。
7. 在模型外后融合成熟过程、PTM 串扰和通路证据，形成证据卡。
8. 按预注册规则去冗余、建立匹配对照、盲法编号、哈希和冻结。
9. 盲法实验完成并返回全部结果后，一次性解盲分析。

零标签迁移副臂使用相同的特征接口，但模型 `S_X` 只由非番茄源域训练；
番茄参考蛋白组只能用于生成待评分序列和结构，不能用于任何有标签调参。

## 5. 组件与接口

### 5.1 Candidate Registry

输入为注册参考蛋白组和正式提供的位点表；输出稳定键
`(species, protein_accession, cysteine_position)`。任何 accession 不存在、
位置越界或目标残基不是 Cys 的行均 fail closed，并记录丢弃原因。

### 5.2 Core Feature Builder

输出 6–10 个标量核心生物学特征。所有需要学习的缩放、降维和选择只在
训练折拟合。缺失生物学值不得猜测性填补。

### 5.3 Tomato Biological Ranker

采用小样本可控的正则化加性排序器。核心形式为：

`S_T = f_seq(X_core) + delta * f_struct(X_struct)`

`f_seq` 是带 elastic-net 正则的主排序器；`f_struct` 是至多三个真实结构
微环境特征的残差校正。`delta` 默认固定为 0，只有结构准入闸门通过后才
能在冻结版本中设为 1。

### 5.4 Observation Propensity Module

只有取得完整、可追溯的发现型质谱观测表时，才允许用可酶切肽段数、肽段
长度/电荷/可检测性代理、蛋白长度、Cys 数、实验批次和化学方法拟合
`q_obs`。没有该表时模块显式关闭，主模型使用同蛋白内排序和分层敏感性
分析；不得生成替代数据。

### 5.5 Cross-Crop Target-Label-Free Ranker

`S_X = f_shared(X_conserved)` 使用水稻和拟南芥公开正例及各自未标记池训练：

- 不包含番茄 99 个 KIAE271 标签或任何其他番茄阳性标签。
- 不使用物种、研究、实验室 one-hot 或蛋白 accession。
- 超参数只能在源域的留物种/留研究或同源簇内层验证中选择。
- 番茄标签不能参与拟合、选择或监督校准；输出只解释为零标签迁移相对排名。
- 稻瘟菌可作距离更远的压力测试，不作为“跨作物”训练证据的必要组成。

### 5.6 Evidence Integrator

成熟期表达、PTM 串扰、通路/网络、文献和机制可行性形成独立证据维度，
不得以一个未经验证的人工权重重新定义 `S_T` 或 `S_X`。证据卡可以用于
预注册去冗余和机制实验可行性排序，但必须保留原始模型名次。

### 5.7 Candidate Release Builder

输出盲法 ID、模型臂、匹配层、实验读出、已知阳性过程对照和哈希清单。
实验执行者不可见模型分数和真实臂标签。

## 6. 特征白名单与禁止项

| 特征族 | 进入位置 | 规则 |
|---|---|---|
| 局部序列化学 | `S_T`、`S_X` | 局部 K/R 密度、疏水性、局部 Cys 密度、酸/碱性比例、复杂度或无序倾向；首版合计受维度上限约束 |
| 位点级保守性 | 候选核心特征 | 只在直系同源映射、Cys 坐标和 MSA 质量达标时使用；全流程记录缺失原因 |
| 结构微环境 | `f_struct` | 真实 SASA/相对可及性、二级结构、局部接触、氢键/盐桥潜力；至多 3 个标量 |
| pLDDT | 质量控制 | 只决定结构特征是否可信，不得作为生物学倾向输入 |
| 冻结蛋白语言模型 | 候选消融 | 只使用局部嵌入，折内降至最多 4 维；必须通过增益闸门才保留 |
| 生物学上下文 | 模型外后融合 | 成熟期表达、PTM 串扰和网络证据不进入训练损失 |
| 质谱可观测性 | `q_obs` | 仅在完整发现型观测表存在时启用 |

禁止进入 `S_T` 或 `S_X`：

- 蛋白 accession、PANTHER 家族 ID、物种/研究/实验室 one-hot；
- 是否存在 AlphaFold/PDB 结构、结构覆盖率或缺失标记；
- 是否被当前质谱鉴定、阳性发现频率或出版来源；
- 未来 lockbox、盲法实验结果或未公开合作数据；
- PPI、AF3、Boltz-2、PLIP、对接或 MD 分数；
- 对缺失结构或生物学变量的猜测性填补。

## 7. PU 损失与不确定性

番茄主模型的训练目标为：

`L = L_within-protein-pairwise + lambda * L_nnPU + alpha * ||theta||^2`

- 同蛋白 pairwise 项要求已观测位点总体高于同蛋白其他 Cys，降低蛋白丰度
  和蛋白级检出性的混杂；未标记位点仍不被定义为真阴性。
- nnPU 项保留蛋白间信息并限制灵活模型的负风险过拟合。
- 阳性先验使用预注册区间做敏感性分析，不设为从当前数据中反复调优的单值。
- 全局 Elkan–Noto `c` 保留为历史基线，不作为主模型训练机制。

不确定性来自同源簇重采样、重复折和固定模型种子的 rank distribution，
而不是仅依赖 MC dropout。每个位点输出：中位名次、名次区间、适用域、
核心特征完整性和结构残差启用状态。盲法 Top-K 使用预注册的保守分位数
分数；高均值但不稳定的位点不能进入 A 级候选。

## 8. 评估轨道与准入闸门

### 8.1 评估轨道

1. **番茄开发主轨**：重复 5 折同源簇分组 CV，panel arena 为模型选择
   主场景；proteome arena 只作现实压力测试和混杂审计。
2. **强制基线 B**：PU logistic、浅层树模型或简单 pairwise ranker 的折外
   rank aggregation；复杂主模型必须证明增益。
3. **文献比较轨**：随机蛋白划分只作同口径展示，永不进入 Gate 2 或泛化
   结论。
4. **跨作物开发轨**：源域留物种/留研究测试用于决定 `S_X` 是否有资格占用
   湿实验候选容量，不把已查看的水稻结果重新称为 lockbox。
5. **唯一主证据**：未来冻结番茄盲法队列。

### 8.2 番茄模型准入

A 主模型只有在预注册 K 下，Recall@K、富集倍数和 MRR 与 B 做逐折/逐重复
配对比较后，保守效应区间仍优于 B，才可替代 B。否则直接冻结更简单的 B。

结构残差还必须满足：

- 在结构可用且覆盖匹配的候选分层内稳定增益；
- “仅结构覆盖”负对照无增益；
- 结果不由单一 fold、seed、蛋白家族或研究来源驱动。

任一条件失败即 `delta=0`。

### 8.3 零标签迁移副臂准入

只有以下条件全部满足，`S_X` 才进入湿实验：

1. 源域留出评估中相对无迁移基线的配对效应方向稳定，且不由单一源研究驱动；
2. 无物种/实验室/结构覆盖捷径，番茄标签泄漏测试为零；
3. 候选适用域覆盖达到预注册要求；
4. 在不降低番茄主终点功效的前提下，实验总容量仍支持独立 X 臂分析。

若第 4 条失败，X 臂只生成冻结计算清单，不进入湿实验，不作预测声明。

## 9. 盲法候选设计

实验容量 `N_total` 必须先由命中定义、预期基准命中率、目标富集和功效分析
确定，再冻结 K；不能按模型结果决定样本数。

候选包含：

- `T` 主臂：由番茄冻结模型独立选择；
- `X` 副臂：只由零标签迁移模型选择，且排除已进入 T 主臂的候选，以保证归因；
- 匹配未标记对照：按蛋白或可观测性代理匹配，不称为真阴性；
- 已知阳性过程对照：只验证实验流程，不计入新候选命中率。

X 副臂默认最多占非对照候选的 25%。若功效分析要求更大份额，关闭 X 臂，
而不是削弱 T 主终点。每蛋白默认最多一个新位点，并限制同源家族和通路
过度集中；去冗余规则在候选生成前预注册。

冻结包至少包含 blind ID、模型/特征哈希、原始与去冗余名次、匹配层、命中
定义、统计分析计划、全结果返回要求、解盲条件和 git tag。冻结后零重排。

## 10. 机制模拟的衔接

机制模块只在盲法确认命中的 1–2 个位点启动：

1. 位点级 persulfidation 确认；
2. Cys→Ser/Ala 或适当突变；
3. 功能、表型和救援；
4. 若有具体诱饵—伙伴假说，再进行 PPLM 二元互作预过滤、AF3/Boltz 复合体
   复核和 PLIP 接触注释；
5. 对接/MD 比较 WT-SH、Cys-SSH 与突变体构象；Cys-SSH 必须有可审计的
   非标准残基参数；
6. 若声称硫转移反应或成键机制，使用 QM/MM；普通 MD 只能支持构象后果。

模拟不得反向修改候选排名。没有实验闭环时只解释为机制假说。

## 11. Fail-closed 与失败后的论文边界

- 核心特征缺失或超出适用域：候选降级或排除，不补值。
- 没有完整发现型观测表：关闭 `q_obs`，不构造替代数据。
- 结构增益未过闸门：发布序列主模型，`delta=0`。
- A 未稳定优于 B：发布 B。
- X 未过计算或功效闸门：不占用湿实验容量。
- 番茄盲法不富集：停止调参，降级为回顾性/方法学论文。
- X 不富集但 T 富集：保留番茄主结论，如实报告跨作物负结果或作为边界分析。
- X 富集但尚无第二作物盲法：主张零标签迁移至番茄，不主张通用泛化。
- 无独立 lockbox：不作 NC 级预测泛化主张。

## 12. 测试与科学完整性要求

实现必须按项目 TDD 合同拆成经 reviewer 单独批准的任务。预期最小测试面：

1. 候选坐标、来源和 SHA256 fail-closed；
2. 同源簇不得跨 train/validation/test；
3. 未标记位点永不转换为硬阴性；
4. 所有 scaler、降维、特征选择和先验选择均为 fold-local；
5. 缺失结构不产生可学习的覆盖标记；
6. `q_obs` 缺少合规输入时必须拒绝启用；
7. `S_X` 的训练依赖图中不得出现任何番茄阳性标签；
8. 随机蛋白、开发 CV 和 X 轨道不能进入 Gate 2 主证据；
9. 候选冻结包哈希、盲法编号与零重排规则可机器验证；
10. 任务测试、fast tests、scientific integrity、release、Ruff 和 mypy 全绿。

每个实现任务必须按 TDD 文档模板报告 RED/GREEN 命令、数据来源、完整性
检查、限制和 commit SHA。本文不授权立即实现这些任务。

## 13. 可审计输入与依据

- 番茄 KIAE271：99 个坐标核验位点/88 蛋白，现有同源簇 CV 结果表明局部
  正电环境有增益，结构分支在 proteome arena 存在严重覆盖混杂。
- 水稻 PXD072089：论文报告 1,691 位点；项目当前从 SD01、SD04 和
  SS-all-peptides 三源得到 929 个坐标核验位点/671 蛋白。原始沉积包括
  PXD072089、PXD072035 和 PXD072300。
- 当前跨物种直接迁移仅为弱信号且 seed 不稳定；多物种联合 LOSO 对各物种
  约等于基准率。因此跨作物被设计为高收益、有界风险副臂，而非共同主任务。
- SAR-PU 用于处理“阳性被观察概率依赖特征”的情形；nnPU 用于限制灵活
  PU 模型的负风险过拟合。二者都不能替代真实的独立盲法验证。
