# 多物种联合训练 v1:物种特异性问题的经验答案

> 日期:2026-08-10 | 分支:phase-a-persulfidation-site-evidence
> 前置:`docs/gate2_condition3_kiae271_expansion_2026-08-10.md`(番茄数据)、`docs/tomato_local_model_v1_2026-08-10.md`(番茄本地模型,由工作线 B 产出)

## 1. 研究问题

用户问:位点预测有物种特异性吗?还是都一样的?多物种联合训练能提升预测吗,需要注意什么?

## 2. 文献调研结论(磷酸化领域是研究最充分的参照)

- **GPS 6.0**(Chen et al., NAR 2023):49 万位点训练通用模型 + 迁移学习做 577 个激酶特异预测器,覆盖 185 物种——"通用模型 + 特异微调"是标准架构。
- **大豆跨物种研究**:8 个物种合并训练时,CD-HIT 65% 聚类去冗余;**同源簇内正负冲突按正例处理**(其他物种的"负例"很可能是未发现的正例——与本项目 PU 语义完全一致);**物种特异实例权重**(源物种与目标物种位点保守度越高权重越高)。
- **进化保守性是最强特征之一**:S-sulfenylation 预测中 PSSM 进化特征(89.25%)远胜 BLOSUM(82.38%)和氨基酸组成(69.52%)。
- **物种特异 motif 真实存在**(真核物种间磷酸化 n-gram 差异),但深层模型能隐式学到。
- **领域现状**:至今没有 persulfidation 特异性预测器;现有 Cys 氧化 PTM 工具普遍"只用人/拟南芥训练、缺结构上下文、无标准化基准"(2025 IJMS 综述)。

## 3. 实验设计(v1)

| 要素 | 方案 |
|---|---|
| 数据 | 拟南芥 390(benchmark)+ 番茄 99(kiae271)+ 水稻 929(PXD072089)+ 真菌 1,482(PXD063170)= **2,900 正例** |
| 分组/防泄漏 | PANTHER 家族级 ID(PTHR#####,去掉 SF 后缀——家族级才能跨远缘物种对齐);无家族蛋白按蛋白级单例分组;同组永不跨折 |
| 特征 | 疏水性、Cys 密度、局部正电荷密度(硫醇盐稳定化先验)+ 家族物种广度、家族成员数(注释层计算,无 label 泄漏)+ 物种 one-hot(4 维) |
| 模型 | Elkan-Noto PU 逻辑回归(共享打分器,5 种子集成) |
| 评估 | ① 家族分组 5 折 CV:test 正例 + 全部未标注背景混合评估(修复了"全正例 AP=1.0"的评估 bug);② **留一物种(LOSO)**:训练其他 3 物种,在从未见过的物种上评估 |
| 对照 | 拟南芥-only 模型在相同 fold 上评估 |

## 4. 结果

### 4.1 家族分组 CV:多物种联合 AP 0.0587 vs 拟南芥-only 0.0095(6.2 倍)

五个 fold 一致(0.056-0.061 vs 0.009-0.010)。按物种分层,信号几乎全部来自真菌(AP 0.087-0.096),其余物种 0.002-0.013。

### 4.2 留一物种(LOSO):全部 ≈1.0x base rate = 无跨物种信号

| 留出物种 | AP | base rate | 富集 |
|---|---|---|---|
| 拟南芥 | 0.0186 | 0.0193 | 0.96x |
| 番茄 | 0.0078 | 0.0078 | 1.00x |
| 水稻 | 0.0400 | 0.0444 | 0.90x |
| 真菌 | 0.2979 | 0.2965 | 1.00x |

### 4.3 双重结论

1. **物种特异性极强**:在当前特征(疏水性 + Cys 密度 + 正电荷密度 + 家族统计)下,模型学到的是"物种内分布记忆"而非通用反应化学——LOSO 全部随机,与此前"拟南芥→番茄 48.5% 恢复率(p=0.84)"的负结果一致,现在有了 4 个方向的系统性证据。
2. **多物种联合训练的 6 倍收益是"见过该物种"带来的,不是通用信号**:真菌正例最多、该物种 AP 最高;留出任何物种后收益消失。这精确划定了多物种模型的适用边界:**在目标物种已有数据时做候选排序有用(AP 6x 于单物种模型);预测完全陌生的物种无用**。

## 5. 为什么通用信号这么难:三个已知因素

1. **标签质量**:未标注池里大部分是"可修饰但未检测到",二分类在学"可检测性"而非"可修饰性"(见 `docs/tomato_local_model_v1_2026-08-10.md` 的检测偏差证据:阳性 93% 有结构 vs 背景 0.1%)。
2. **特征离机制远**:决定修饰的因果变量(H2S 来源浓度、局部氧化还原状态、蛋白互作、底物动力学)都没有特征表示;正电荷密度是唯一靠近因果链的特征,它只在同物种内有效,说明它捕捉的也是分布内的统计规律。
3. **同源保守性特征缺失**:文献表明 PSSM/进化保守性是最强 PTM 特征,但 v1 只用了家族级统计(物种广度、成员数),没有**位置级**同源保守性(需要跨物种 MSA 才能知道"同源位置的 Cys 是否保守")——这是 v2 最优先的特征方向。

## 7. 与 Gate 2 的关系

本实验是候选排序评估,不是跨研究预测验证;`GATE2_STOP` 判定未受影响、`configs/gate2_v1.yaml` 未改动。LOSO 结果进一步佐证了 STOP 的合理性:跨物种预测在现有特征下无信号。

## 8. v2 方向(按预期价值排序)

1. **位置级同源保守性特征**:跨物种 MSA,计算"该 Cys 在同源位点保守比例"——文献最强的 PTM 特征,需要每家族多序列比对(MMseqs2 + MSA,可用远程 A100)。
2. **结构特征接入**:拟南芥/水稻/真菌已有 AlphaFold 覆盖;番茄 82/88。但注意工作线 A 的检测偏差教训:阳性/背景结构覆盖率不对称时结构特征退化为"可检测性代理"。
3. **连续谱框架**:把二分类改成排序/回归,用 kiae271 定量强度或"被检测到的条件数"做软标签。
4. **species-aware 分层评估**:LOSO 作为标准评估维度纳入后续所有实验。
