# 张华实验室交接包：蛋白内位点定位突变验证方案（2026-08-16）

> 建模方决策（2026-08-16）：验证模式从"预注册盲测 MS 检测"改为 **Cys→Ala 突变 + 功能读数**，
> 任务框架为**蛋白内位点定位**（给定蛋白，模型排序其全部 Cys，预测修饰位点）。本文件是交接
> 包的主文档；配套数据文件见文末清单。候选/对照在实验结果返回前锁定。

## 1. 设计（一句话）

每个目标蛋白：模型给出该蛋白全部 Cys 的排名，预测位点 = rank-1 Cys；
实验室把 **rank-1 Cys→Ala** 与 **2–3 个蛋白内对照 Cys→Ala**（rank-2..4）做成突变体，
测同一个功能读数，比较 WT 与突变体。

## 2. 为什么是蛋白内对照

- Cys→Ala 突变**本身可能破坏蛋白结构/功能**（与持硫化无关）——这是该验证路线最大的混淆。
  蛋白内对照（同蛋白、同折叠背景的其它 Cys）把这种非特异效应基线化：如果 rank-1 突变体
  表型改变而蛋白内对照突变体不变，才支持"该位点特异"。
- 验证的是**模型定位**：模型预测"这个蛋白里是 Cys 171"，而不是"这个蛋白是持硫化靶标"。

## 3. 目标蛋白与预测（`zhang_assayable_proteins_v2.tsv`，25 个）

- 选择规则（fail-closed，选前未看任何功能结果）：
  - 排除 Uncharacterized / Fragment / Metallothionein / Snakin-defensin / 富 Cys 小肽；
  - 要求 ≥3 Cys、蛋白长度 ≥150 aa；
  - 剩余按模型蛋白内 rank-1 分数排序，取前 25。
- 每行含：蛋白 accession、功能注释、n Cys、**预测位点 + ±10 序列窗口**、rank-1/rank-2
  分数差（gap）、该蛋白全部 Cys 排名。
- **实验室应从中挑有现成功能读数的子集**（E3 连接酶/RING 可测泛素化或互作、锌指可测
  转录活性、蛋白酶抑制剂可测抑制活性等）。建模方不替实验室指定具体读数。

## 4. 分析（预先指定，防后调）

对测过的蛋白（实验室能出读数的那些）：

- **主分析**：预测位点突变体出现功能表型（活性/互作/稳定性改变）的比例 **vs** 蛋白内对照
  突变体出现功能表型的比例；单侧 Fisher 精确检验 + OR + 95% CI。
- **成功标准**（预先声明）：p < 0.05 且 OR > 1，且 ≥2 个蛋白的预测位点突变体出现表型。
- **敏感分析**：(i) 排除蛋白内对照 <2 的蛋白；(ii) 把"预测位点"放宽到模型 rank-1..2
  （因为蛋白内 gap 扁平，rank-1/rank-2 经常接近）；(iii) 排除训练面板蛋白。

## 5. 诚实的预期与局限

- **模型的番茄信号是弱到中等的**：金标准对照蛋白内 Hit@2 6/12（v2）、干净未训练 kiae271
  位点 4/17；蛋白内排名 gap 扁平（median ~3e-5，分数分辨率限制）。**预期富集温和**
  （OR 量级 1.5–2.5，与 v1 预盲校准一致），设计按此定效度。
- Cys→Ala 表型 ≠ 持硫化证明（可能只是该 Cys 结构关键）；本验证的声称是"**模型定位的位点
  更可能功能重要**"，不是"该 Cys 被持硫化"。MS 确认留给建模方后续或其它管线。
- 本交接包的信号强度不因过滤而改变——过滤只是让蛋白可测，不是提高模型性能。
