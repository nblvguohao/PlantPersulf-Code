## Reviewer 1（technical soundness 权重最高）

- **Overall assessment**: 统计与治理层面的严谨度显著高于领域常态：冻结工件、SHA256 注册、单次解锁 + run-manifest 审计、预注册声明门、诚实的功效列表、检测下限。框架的技术性是成立的。但**保守性分析有一个未处理的替代解释**（见下），它直接动摇「靶向保守」这一生物学主张的强度；资源支柱的主结果又尚未存在，因此从技术上讲，这篇稿子的「case」目前只完成了一半。
- **Who would be interested in the results, and why**: 植物氧化还原/H₂S 信号研究组（会直接采用番茄候选表与保守性结论）；化学蛋白质组学方法学家（检测下限与 pLDDT 混淆这两条方法学提醒）；PTM 生物信息学工具开发者（把预注册/冻结流程当模板）。
- **Major strengths**:
  1. **检测下限（detectability floor）** 是真正的报告方法贡献：把「p=0.46」转译成「最多只能检出 3.3× 富集」，是把欠功效零结果写对的做法。
  2. **pLDDT 混淆自纠错** 链条完整（朴素信号 → 置信度差 → 置信度限制后塌缩，且番茄 wt_only 层被定位为驱动），并且是全文撤回而非含糊其辞。
  3. 冻结工件与声明门「有牙齿」：番茄差异 −0.0004 导致严格冻结测试拒绝更强声明类别，这一事实本身就证明了机器的可信度。
- **Major concerns**:
  1. **丰度/可检出性混淆未被控制（本轮最重要、且前两轮内部评审未触及的发现）**。化学蛋白质组学中过硫化的检出强烈偏向高丰度蛋白；而论文发现的「保守靶标集合」（果糖-1,6-二磷酸酶、甘氨酸脱氢酶、复合体 I 75kDa 亚基、山梨醇/L-苏糖酸脱氢酶）恰好都是任何细胞里丰度最高的中枢代谢酶。置换零假设固定了每个物种自身的边际计数，**但它没有排除「同一批高丰度家族在每个研究里因丰度原因被独立检出」这一替代解释**——而这正是跨研究 PTM 靶标「保守性」的经典伪信号来源。论文用「独立实验室、独立化学、独立物种」来论证保守，但这三种独立性都**不能**消除「高丰度蛋白在所有研究里都被检出」的共变。至少需要一个丰度/表达条件化的对照（例如在丰度匹配的子家族上重跑零假设，或用 iBAQ/emPAI 排序后分层，或与一个非过硫化对照 PTM 做相同检验）来确立保守性主张。八家族身份的「中枢代谢」富集非但不能缓解此顾虑，反而使之更尖锐。
  2. **效应量本身很小，显著性由大样本量驱动**。Arabidopsis×Rice 是 21/9,188（2.96×），Rice×*Magnaporthe* 是 67/2,320（2.22×）。这些是「真实但弱」的保守信号，讨论部分应避免让读者读成「强保守」。当前文本在数值上诚实，但「conserved」一词在摘要与讨论中被反复使用，未配一个显式的效应量说明。
  3. **严格冻结测试的「125×/133× base rate」措辞有误导风险**。绝对 AP 是 0.0996 / 0.1978，意味着头部预测里 80–90% 仍是错的；用 base-rate 倍数包装会把读者引向两三个数量级的印象。校准段已部分对冲，但摘要与 R4 仍在强调倍数。
- **Technical failings that need to be addressed before the case is established**:
  1. 保守性检验缺丰度/可检出性对照（见 Major concern 1）——在补齐前，「靶向保守」主张只能以「关联性、可能受丰度混淆」的弱化措辞陈述。
  2. 校准的独立对照样本量过小：7 个拟南芥对照（5/7 上中位，p=0.45）与 20 个干净番茄位点（13/20，p=0.26）都不足以区分「弱信号」与「无信号」，先验 OR 1.5–2.5 本质上是一个受控猜测。文本对此已诚实标注，但应明确说「校准结果是 inconclusive 而非 mild positive」。
- **Assessment against Nature-style criteria**:
  - *originality*: 跨界保守性检验是首个直接检验；自纠错是方法学原创；但资源支柱的原创性在「治理流程」而非「生物学发现」。
  - *scientific importance*: 领域内重要；尚未达到跨领域层面的「outstanding」。
  - *interdisciplinary readership*: 对方法学与元科学读者有吸引力，对植物生物学读者的核心卖点被主结果缺失削弱。
  - *technical soundness*: 框架部分强；保守性主张因丰度混淆而未完全确立。
  - *readability*: 对非专家读者偏重（哈希/解锁/manifest 词汇密集）。
- **Recommendation posture**: 框架部分技术上稳健；保守性主张需丰度对照后才是「已确立」；主结果缺失使技术评估只能完成一半。

## Risk / unsupported claims

- **「conserved targeting」的生物学强度** — **未完全确立**：无丰度/可检出性对照，效应量小（2.2–3.0×，绝对共过硫化家族数 21/67/8），「conserved」一词需配效应量否则有过度解读之嫌。
- **资源支柱的主实验结论（盲法验证候选排序有效性）** — **不存在/不可评估**：Gate 3 占位，两个目标期刊均不可据此评估。
- **「125×/133× base rate」** — **易误导**：绝对 AP 0.0996/0.1978，头部预测 80–90% 仍错；倍数措辞夸大读者印象。
- **先验 OR 1.5–2.5** — **本质是受控猜测**：校准样本量（7+20）不足以区分弱信号与无信号，应定性为 inconclusive。
- **「首个性」/新颖性** — 跨界检验与自纠错为真原创；「资源+协议」的原创是流程层面，且其新颖性论述仅靠两条元科学引用支撑，略显单薄。
- **与目标期刊的适配** — 生物学支柱对 Plant Physiology 高度契合（kiae271 即 PP 论文）；Communications Biology 以「完整结果」为前提，保守性结论单独（弱效应量、关联性）可能低于其「推进领域」门槛，组合资源后或有吸引力，但仅在 Gate 3 完成后。作者应核实两刊是否接受「注册报告」格式——评审人理解二者均无此投稿类别，但此点需作者确认，不宜作为定论。
