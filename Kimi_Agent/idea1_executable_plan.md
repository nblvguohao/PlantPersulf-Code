### 2. 番茄/蔷薇科转录组与表观组（全部免费公开）

- **番茄成熟时序**：TomExpress（38 数据集/1201 统一样本）；GSE148217、GSE116581、GSE163745（WT/Cnr/nor/rin 成熟突变体 RNA-seq，4 重复）。
- **成熟调控因子结合数据**：NOR ChIP-seq（PRJNA309352）；**fruitENCODE（PRJNA381300）= 355 个转录组 + 160 组蛋白修饰 + 45 甲基化 + 66 染色质可及性，覆盖 11 种肉质果含番茄和桃**；番茄 Cnr 甲基化数据经 fruitENCODE 可得。
- **梨**：'Starkrimson' 红/绿皮转录组（PRJNA290937，正是 kiad068 借用的那套数据，**确认公开**）；'红早酥' 光诱导果皮转录组（NGDC PRJCA009255，27 样本）；梨基因组数据库 PGDB。
- **草莓/桃/苹果**成熟与花青素转录组均有公开数据。
- **数据库**：JASPAR plants、PlantTFDB（番茄 1845 个 TF）、STRING（番茄、梨均收录）——全部免费。

### 3. 结构数据与计算工具

- **AlphaFold DB 已覆盖**：SlWRKY6、SlMAPK4、BRG3、CAS1、PyMYB10、PyERF4 均有现成结构（已用 API 逐一验证）；仅 WRKY71、PyMYB73、PyMYB6 需用 ColabFold/AlphaFold3 server 自行预测（均为 <600 aa 小蛋白，完全可行）。
- **PTM 预测工具**：SNO 预测器成熟（DeepNitro、pLMSNOSite 等 6+ 款）；**专门的过硫化预测器基本空白**——唯一覆盖的是 pCysMod（2021，S-sulfhydration AUC≈0.793）。→ **这是可以直接填的空白，是本文最大的方法学创新空间。**
- **MD 模拟**：Vienna-PTM（GROMOS 力场 250 种 PTM 参数化 + webserver）、PyTMs 可用；-SSH 残基需基于硫醇参数派生，已有拟南芥 UGT71C5 过硫化"预测→模拟→验证"的范式先例（IJMS 2024）。
- **数据库空白确认**：Plant PTM Viewer 2.0（植物，有 SNO 无过硫化）、dbPTM 2025（动物为主，无 persulfidation 独立类型）、PhosPhAt（仅磷酸化）。**"植物专用、含过硫化-亚硝基化串扰的整合 oxiPTM 数据库"确实空白**（已证实）。

## 二、可执行方案

### 总体设计：四层金字塔

```
Layer 4  故事层：把计算发现收束到"成熟/着色调控"的具体可检验预测
Layer 3  机制层：候选开关分子的结构模拟 + 调控网络定位
Layer 2  规律层：首个植物过硫化深度学习预测器 + 多PTM串扰图谱
Layer 1  资源层：PlantOxiPTM 数据库（PRIDE 重搜库 + 文献位点整合）
```

### 模块与任务分解

**M1 资源层——PlantOxiPTM 数据库构建（第 1–4 月）**
- 下载核查清单中 15+ 套 PRIDE 原始质谱数据（mzML/mgf），用统一流程（FragPipe PTM workflow / pLink-SS 式 tag-switch 搜索）重搜库，统一 FDR 与位点定位标准——**解决原数据集方法学不可比的问题，这本身是贡献**；
- 整合文献中位点级 PTM 数据（含上传文献的 SlWRKY6 C396、BRG3 C206/212、PyMYB10 C194/218、HA2 C206 等）；
- 输出：跨 8+ 物种、预计 1–2 万位点的植物 oxiPTM 统一目录 + 可在线查询的网页数据库（配合序列保守性、结构可及性注释）。
- 风险对冲：先完成拟南芥+番茄两个物种作为 pilot。

**M2 规律层——预测器与串扰图谱（第 3–8 月）**
- 用 M1 的高质量位点集训练**首个专门的植物过硫化深度学习预测器**（ESM2/ProtT5 蛋白语言模型 embedding + 轻量分类头，对标 pLMSNOSite 路线）；基准对比 pCysMod；
- 构建"过硫化 × SNO × 磷酸化 × 泛素化"位点级共现/竞争图谱：映射到磷酸化（PhosPhAt、qPhos）、泛素化公开位点库，统计同一 Cys 及邻近窗口内的串扰富集；
- 输出：PTM 串扰的全蛋白质组统计规律 + 预测器 web 工具。

**M3 机制层——聚焦成熟/着色系统（第 6–10 月）**
- 用 fruitENCODE + TomExpress + GSE148217 做番茄成熟 GRN 重建（WGCNA + regulon 推断），把 M2 图谱中被预测携带氧化还原开关的 TF/E3 投射到成熟网络上，筛"高串扰得分 × 高网络中心性"的枢纽分子；
- 对 top 枢纽（含原文献四分子 + 新预测分子）做 AlphaFold3/ColabFold 复合体结构 + -SSH 修饰建模 + 短程 MD，给出"修饰如何改变 DNA 结合界面"的原子级假说；
- 梨/蔷薇科比较基因组：AP2/ERF、R2R3-MYB 家族 EAR 基序与 Cys 保守性扫描，预测跨物种保守的氧化还原开关。

**M4 验证与故事层（第 9–12 月）**
- 用 PXD056815（番茄 SNO 定量组）与 PXD039999（干旱过硫化组）做独立数据集回测，检验预测器与串扰规律在"未参与训练"的数据上的泛化；
- 输出 5–10 个可湿实验验证的优先候选清单（如预测某成熟 E3 连接酶的特定位点），供合作者做 PRM 靶向质谱/点突变验证——把纯计算论文升级为"计算+关键验证"，达到 Nat Commun/Nat Plants 门槛。

### 里程碑与产出物

| 时间 | 里程碑 | 产出 |
|---|---|---|
| M4 | M1 完成 | 数据库 + pilot 分析（可作预印本/数据库短文，NAR Database issue） |
| M8 | M2 完成 | 预测器 + 串扰图谱 |
| M10 | M3 完成 | 成熟网络枢纽清单 + 结构机制假说 |
| M12 | M4 + 成文 | 主文投 Nat Commun / Nat Plants；数据库单独投 NAR |

### 团队/算力需求

- 1 名生信（质谱重搜库+网络分析）、1 名 ML（预测器）、1 名结构计算（可兼职）；GPU 单机（ESM2 embedding + 小规模训练）即可；质谱重搜库需 ~50–100 CPU 核周级算力。
- 主要风险：① 各 PRIDE 数据集 tag-switch 标记化学不同导致位点集异质——用统一重搜库 + 严格定位分数阈值对冲；② 过硫化训练位点仅约数千、类别不平衡——用迁移学习（从 SNO/磷酸化模型初始化）+ 数据增广对冲；③ 番茄过硫化组学数据缺失——正是空白，用预测器+番茄 SNO 数据填补。

## 三、通俗示例：这篇文章到底在做什么？

**一句话版：把"植物闻气体的本事"从一个个案研究，变成一张可预测的全景地图。**

打个比方。番茄和梨在成熟、变红、抗逆时，靠一氧化氮（NO）和硫化氢（H₂S）这两种"气体信号"给蛋白质"贴便签"——在半胱氨酸上加一个硫原子（过硫化）或硝基（亚硝基化），蛋白的功能就被拨动了开关。你上传的这些论文，每篇都发现了一个这样的开关：比如"H₂S 给 MYB10 贴便签 → 梨不变红""H₂S 给 WRKY6 贴便签 → 番茄晚熟"。

问题是：**全世界实验室都在一个一个地撞大运式地找便签**——每篇文章耗费数年、只能验证一两个位点，而且没人知道植物体内到底有几千个还是几万个这样的便签、它们贴在哪里、彼此之间抢不抢位置（过硫化和磷酸化常常竞争同一位点）。

这篇文章要做的，就是**用计算机把已经公开躺在数据库里的十几套质谱数据（相当于几千次实验的原始记录）全部重新挖一遍，建第一张"植物气体信号便签全图"，再训练一个 AI：给它任何一个植物蛋白的序列，它就能预测这个蛋白哪里可能被贴便签、贴了以后会怎样**。最后用番茄成熟这个大家最关心的系统来证明地图有用——预测出几个前人没发现的新开关，并用结构模拟讲清楚"这个便签是怎么把蛋白拨到另一档的"。

**它现在的价值**：① 领域正热——H₂S/过硫化是植物信号近五年的明星方向（Plant Cell 2025 还在发番茄 SNO 组学），但计算工具和数据整合明显滞后于湿实验，综述（如你上传的 COPLBI 稿）公开喊话需要定量与整合研究；② 实用——预测的开关位点直接指向耐逆、调控成熟期的分子育种靶点；③ 时机——PRIDE 里这些数据 2023–2025 年才刚凑齐规模，此前想做也做不了。

**与同方向文章的不同**：现有文章是"点"（一个蛋白、一个位点、一套湿实验），我们做的是"面+预测器"（全蛋白质组规律 + 可泛化的 AI 工具 + 开放数据库）。已有的最接近资源（Plant PTM Viewer、dbPTM）都不含过硫化、不做植物专用串扰；已有的预测器只有 pCysMod 勉强覆盖过硫化且精度有限、非植物专用。

**创新点（三条，均可被核查证实为空白）**：
1. **首个植物专用、覆盖过硫化–亚硝基化串扰的 oxiPTM 整合数据库**（Plant PTM Viewer 无过硫化、dbPTM 无 persulfidation 类型）；
2. **首个专门的过硫化深度学习预测器**（该修饰类型目前无专用预测器），并把"多 PTM 竞争同一位点"做成全蛋白质组定量图谱；
3. **把气体信号 PTM 层首次系统接入果实成熟调控网络**（fruitENCODE/TomExpress 多组学），产出可验证的新调控枢纽预测——从"事后解释单点"升级为"事前预测系统"。
